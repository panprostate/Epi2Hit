This folder contains **publicly available reference files and example inputs** used to reproduce parts of the Epi2Hit workflow and to support the **containerized demo/test run**.  The primary discovery analyses in the manuscript were performed on the **PPCG cohort** (see Methods and companion PPCG resource papers); the full PPCG raw/processed datasets are not redistributed here. Instead, we provide (i) reference annotations and regulatory tracks used for annotation/visualisation and (ii) a compact **TCGA-PRAD chr8** example dataset sufficient to run the workflow end-to-end and reproduce representative outputs.## Contents### 1) TCGA-PRAD chr8 example inputs (reproducibility / Docker demo)These files form a **small, self-contained test dataset** used to run the epi2hit eCpG discovery on chromosome 8.**Core epi2hit inputs**- `chr8_methylation.tsv.gz`    450K methylation β-values (chr8 subset) for TCGA-PRAD samples used in `analysis/TCGA_run.ipynb` and the Docker demo.- `expression.tsv.gz`    Matched gene expression matrix for the same TCGA-PRAD samples.- `Corces_PRAD_Peaks_hg19_chr8.bed.gz`    Prostate ATAC-seq peaks (chr8 subset; hg19) used to restrict CpGs to open chromatin.- `chromHMM_chr8.bed.gz`    Prostate ChromHMM data used for promoter/enhancer state mapping.- `loops.bedpe.gz`    Hi-C loops (BEDPE; hg19) used to annotate CpGs at loop anchors / regulatory contacts.**Inputs for downstream biallelic analysis**- `cBio_prad_tcga_2018_mutations.txt.gz`    TCGA-PRAD mutation calls used by `biallelic_py` - `cBio_prad_tcga_2018_cn_segs_chr8.txt.gz`    Copy-number segments for TCGA-PRAD (chr8 subset) used by `biallelic_py` > Note: These TCGA-PRAD example inputs are included to support end-to-end reproducibility of representative figure panels and to provide a small dataset for testing the containerized workflow.---### 2) Gene annotations (hg19 / GRCh37)- `gencode/`    Auxiliary GENCODE v19 resources used for gene annotation and exon mapping.- `gencode.v19.protein_coding_gene.minimal_chr.bed.gz`    Minimal BED annotation of protein-coding genes (GENCODE v19; hg19/GRCh37), used for probe→gene mapping.---### 3) Regulatory / epigenomic reference tracks (optional annotation & visualisation)These tracks are provided to support **optional plots and locus-level visualisations** (e.g., overlap with promoter marks, enhancers, or CTCF sites). They are not required for the minimal epi2hit run unless explicitly enabled.- `CTCF_GSE123210_ENCFF785IOE_signal_p-value_hg19_sliced.bigWig.gz`    CTCF signal track (hg19; sliced region used for plotting).- `H3K27ac_GSE105424_ENCFF994HZA_signal_p-value_hg19_sliced.bigWig.gz`    H3K27ac signal track (hg19; sliced region used for plotting).- `H3K4me3_GSE96019_ENCFF710JYO_signal_p-value_hg19_sliced.bigWig.gz`    H3K4me3 signal track (hg19; sliced region used for plotting).- `Pomerantz_combined_10_states_colour_final_mod_FOROVERLAP.bed.gz`    Chromatin-state resource used for overlap-based annotation.- `Corces_PRAD_Peaks_hg19_hglft_genome_7dc9_e56a20.bed.gz`    ATAC-seq peaks (full file; hg19) used for broader analyses/annotation.- `GCF_000001405.25_GRCh37.p13_genomic_chr16.gff.gz`    GRCh37 reference annotation fragment used for auxiliary annotations.---## How this folder is used in the workflow- The notebook `analysis/TCGA_run.ipynb` (and the Docker workflow) expects the chr8 inputs above to be available for running the **eCpG discovery pipeline** end-to-end.- The downstream biallelic analysis (`biallelic_py`) uses the mutation and CNA segment example inputs together with the epi2hit output (`eCpGs.tsv`) to generate summary statistics and plots (e.g., biallelic event barplots).For containerized execution and expected mount layout, see **`docker/README.md`**.---## Data provenance and licensingAll files in this folder are derived from **publicly available resources** (TCGA/cBioPortal, GEO, ENCODE, and published prostate epigenomic resources) or are processed subsets used for reproducibility.
